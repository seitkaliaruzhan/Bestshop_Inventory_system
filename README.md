# Best Shop - Inventory Management System

### Стек технологий:
* **Язык:** Python (CustomTkinter)
* **БД:** Microsoft SQL Server
* **Связь:** pyodbc

### Как запустить проект:
1. Выполните скрипт `database_setup.sql` в SQL Server Management Studio для создания таблиц и данных.
2. Установите библиотеки: `pip install customtkinter pyodbc`.
3. Запустите `main.py`.

### Функционал:
* Поиск товаров через хранимые процедуры.
* Фильтрация по категориям и наличию (Views).
* Автоматический расчет общей стоимости склада.
